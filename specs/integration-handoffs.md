## Integration checkpoints and independent preparation

These checkpoints make the existing dependency handoffs concrete. They do not require both humans to be online simultaneously. Record the producing revision, affected contract/scenario IDs, actual agent findings/checks and remaining gates in the assigned change verification. Review completed implementations with an independent agent, including executable configuration and agent/workflow instructions; standalone specification audits require explicit assignment. Evidence/log-only updates do not restart review. After an authorised push, GitHub review is the final PR review. Human reviewer assignment, independence, approval, sign-off and merge readiness are outside agent assessment under the [review policy](../CONTRIBUTING.md#review-records). Integrate prerequisites and rerun affected checks before relying on integrated behaviour; neither a clean merge nor a test double establishes compatibility by itself.

The [CLI deployment route selected on 18 October 2026](../changes/CHG-K-002-wp-001-foundation-design/design.md#selected-cli-deployment-route) governs future build/deployment evidence under G08. Its automation, credential/environment and migration boundaries belong in that design. The existing Production workflow succeeded at `05e1b42`; CHG-K-006 records that run separately from passed non-production connection/replay/upgrade/recovery and hosted persistence checks; SoC remains gated. Handoffs still distinguish method selection, actual results, account/resource facts, eligibility and provider evidence.

The [foundation stack and Neon development/production design selected on 18 October 2026](../changes/CHG-K-002-wp-001-foundation-design/design.md#selected-application-foundation) governs future runtime/data/migration handoffs. Carry locked versions and actual compatibility/isolation/recovery evidence, including any explicitly recorded fallback allowed by the design. Synthetic-only non-production resources remain separate from independent production resources; no production credentials or private data enter development-agent handoffs. Selection alone supplies no account/region/allowance or runtime result; use the assigned change's actual evidence. The database and provider handoffs are independently tracked: incomplete SoC evidence does not block an otherwise completed database handoff, and neither a template nor a successful migration-status step completes that handoff.
